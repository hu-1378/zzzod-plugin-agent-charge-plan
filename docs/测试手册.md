# 测试手册

按顺序走一遍，每步都有「怎么做 / 看什么 / 算通过 / 不通过记什么」。
不用改代码，把结果填进最后的记录模板就行。

> 这个版本有 **3 种运行模式**，先跑 `audit`（只读），确认读得对再往后面走。

| 模式 | 干什么 | 会不会改东西 |
|---|---|---|
| `audit` | 逐个角色读清单、算计划、输出文件夹 | 只读，不改配置、不刷本 |
| `plan_only` | 算计划，写进内置体力计划的配置 | 改 `charge_plan.yml` |
| `execute` | 自己边跑边算边刷 | 真刷，会消耗电量、改游戏里的特训目标 |

---

## 0. 开始前（做一次）

1. **环境**：Windows、1920×1080、游戏语言简体中文（OCR 按中文调过阈值）。**中途不要改分辨率**。
2. **插件位置**：`<一条龙目录>\plugins\agent_charge_plan\`。
3. **刷新**：打开一条龙 → 左侧「插件」→「插件管理」→ 点右上角**刷新**按钮（循环箭头）。
   不用重启一条龙，插件代码和画面定义都会重新加载。
4. **配置文件**：`config/01/one_dragon/agent_charge_plan.yml`（`01` 是你的账号下标）。
   第一次可能不存在，跑一次就会生成。
5. **日志**：`.log\` 目录下最新的那个文件，或者一条龙的日志面板。

## 1. 冒烟：插件认出来了没（2 分钟）

**做什么**

- 看应用列表里有没有「特训目标体力计划」
- 点它的齿轮，能不能打开设置页

**算通过**

- 应用列表里有这个应用
- 设置页能打开，看到 7 个设置项：运行模式 / 目标模式 / 指定代理人 / 只预览不写入 / 只扫描代理人名单 / 默认次数 / 驱动盘也排

**不通过记什么**

- 应用列表里没有 → 复制一条龙启动日志的后 30 行给我
- 设置页打不开或报错 → 复制报错原文

---

## 2. 扫描角色（一次，约 10~30 秒）

**做什么**

1. 设置页把「**只扫描代理人名单**」打开
2. 跑到大世界，点运行这个应用
3. 等它结束

**会看到它做什么**：进快捷手册 → 训练 TAB → 特训目标 → 点「更换特训目标」→ 逐屏读名字 → 关弹窗

**看日志**

```
特训目标体力计划开始：... 扫描模式 True
扫到 N 个代理人：佩洛伊斯、琉音、卢西娅、...
```

**算通过**

- 扫到的**数量**和你在游戏「更换特训目标」里数的一致（一屏 12 个，剩下的靠滚动）
- 名字里没有 `Lv.60`、没有 `S`、没有碎字

**不通过记什么**

- 少了几个 → 记「实际 N 个，扫到 M 个」，我调滚动距离
- 名字有脏字符 → 把扫出来的原始列表抄给我
- 卡住不动 → 日志最后 10 行

**做完**：把「只扫描代理人名单」关掉。

---

## 3. Web 页勾选（2 分钟）

**做什么**

1. 双击 `plugins\agent_charge_plan\web\启动配置页.bat`
2. 浏览器会自动打开 `http://127.0.0.1:23099/`
3. 左上选 实例 `01` / 组 `one_dragon` / 配置 `charge_plan`
4. 页面下方「**要养的角色**」里，勾选你想批量处理的角色
5. 点保存

**算通过**

- 角色列表里能看到第 2 步扫到的名字
- 勾选后保存，绿条显示「已写入 .../agent_charge_plan.yml（备份 .backup/...）」
- 再刷新页面，勾选状态还在

**不通过记什么**

- 列表是空的 → 说明第 2 步没写进配置，回去看第 2 步
- 保存报错 → 复制红条原文

**顺便试**：顶部「复制配置摘要」按钮，能复制出体力计划清单。

## 4. 核对模式（audit）← 建议重点测这个

不动任何配置，只把每个角色读到什么、算出什么都落盘，方便你逐条核对。

**做什么**

1. 设置页「运行模式」选 **全角色核对**
2. 跑到大世界，运行应用
3. 等它跑完（每个角色约 10~20 秒）
4. 打开输出目录

**输出在哪**

```
<一条龙目录>\plugin_data\agent_charge_plan\agent_audit\<时间戳>\
├── 汇总.md
├── README.txt                    ← 说明这是产物，可删
├── 蕾米埃尔·丹\
│   ├── 清单.txt                  ← 分组 / 条目名 / 电量 / 进度
│   ├── 计划.yml                  ← 算出来的计划（可直接和内置 charge_plan.yml 对比）
│   └── 特训目标页.png             ← 整屏截图，右下角 UID 已涂黑
└── 叶瞬光\
    └── ...
```

**看日志**

```
要核对 N 个角色（batch_agent_names / known_agent_list），结果放 ...
核对「蕾米埃尔·丹」...
```

**算通过**

- 每个勾选的角色都有一个文件夹
- `清单.txt` 的条目数和游戏里特训目标页看到的一致
- `计划.yml` 的副本名、次数、卡数看着合理（对不上的条目在 `warnings` 里有原因）
- `汇总.md` 每行一个角色，备注里写清了为什么少了某条
- 截图确实打码了（右下角是黑的）

**不通过记什么**

- 哪个角色漏了 / 清单少了哪条 → 把那个角色的 `清单.txt` 和截图发我
- `计划.yml` 里有认不出的条目 → 把 `warnings` 那段发我
- 跑完特训目标没恢复成原来的 → 记下变成了谁

## 5. 只生成计划（plan_only + 预览）

**做什么**

1. 设置页：运行模式选 **只生成计划**，目标模式选 **按角色养成缺口**，「只预览不写入」**保持打开**
2. 运行应用

**看日志**

```
特训目标：蕾米埃尔·丹，条目 4 个
  代理人 / 调查员记录 / 电量 20-100 / 进度 129/290
[排上] 调查员记录 → 实战模拟室|基础材料|调查专项 次数 1 卡数 5 电量 100
[跳过] xxx：原因
写入结果：预览（没写入），计划项 N 条（新增 a / 更新 b / 保持 c）
```

**算通过**

- 「排上」的副本和你预期一致
- 「跳过」的理由讲得通
- 最后一行明确写着**预览（没写入）**

**不通过记什么**

- 排出来的副本不对 → 把 `[排上]` 那几行发我
- 电量数字明显不对（比如 0）→ 记下游戏里实际电量

## 6. 真写入内置体力计划

**做什么**

1. 关掉「只预览不写入」
2. 运行应用
3. 打开内置「体力计划」应用看一眼计划列表

**算通过**

- 内置体力计划里出现了对应的计划项
- 你自己手工加的计划项没被删
- 再跑第二次，计划项数量不变（不会重复堆）

**不通过记什么**

- 出现重复项 → 把 `charge_plan.yml` 的 `plan_list` 发我
- 用户自己加的被删了 → 同上

## 7. 边刷边算（execute）← 会真的刷本，最后测

**做什么**

1. 设置页：运行模式选 **自己刷**，关掉「只预览不写入」
2. 确认游戏有电量
3. 运行应用

**按这个顺序刷**

```
① 当前角色还有缺口 → 刷一次
② 材料库存还有缺口 → 刷一次
③ 都没活干但电量还有 → 刷保底任务
三者都空 → 换下一个角色 → 继续
电量不够 → 结束
```

**看日志**

```
批量读清单 1/3：蕾米埃尔·丹
[排上] ...
传送 → 刷
```

**算通过**

- 按 ①②③ 的优先级挑活干
- 刷完会重新判断，不会一口气刷同一条
- 一个角色刷完/没得刷，自动切下一个
- 电量用完会正常结束，不卡住
- 跑完特训目标恢复成进来时那个

**不通过记什么**

- 刷错副本 / 卡在某个画面 → 日志最后 20 行 + 当时游戏画面截图
- 电量算错导致刷到一半游戏报不足 → 记下实际电量和日志里的电量
- 特训目标没恢复 → 记下变成了谁

## 8. 常见问题

| 现象 | 多半是 | 怎么办 |
|---|---|---|
| 应用列表没这个插件 | 插件没被发现 | 插件管理页点「刷新」；还不行看启动日志 |
| 设置页改了不生效 | 配置实例缓存 | 再点一次「刷新」，还不行重启一条龙 |
| 找不到特训目标页 | 进页面的路线不通 | 记日志里 `前往训练TAB` 那几行的状态 |
| 扫到的角色少 | 滚动不够 | 记「实际几个 / 扫到几个」 |
| 清单里条目少 | 同上（滚动）或 OCR 漏 | 给那个角色的 `清单.txt` + 截图 |
| 电量显示 0 | 资源栏识别失败 | 记游戏里实际电量，日志里搜「电量识别」 |
| 刷到一半停下 | 电量不足或传送失败 | 日志搜 `记下传送失败` |
| 特训目标被改了没恢复 | 恢复那步失败 | 日志搜「没能恢复」，手动在游戏里改回来 |
