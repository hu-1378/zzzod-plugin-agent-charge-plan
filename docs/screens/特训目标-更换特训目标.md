# 特训目标-更换特训目标

「快捷手册 → 训练 → 特训目标」页点「更换特训目标」弹出的代理人选择弹窗。游戏内**同时只能设一个特训目标**，所以批量配置必须在这个弹窗里逐个切换。

## 何时出现 + 状态流转

- **入口**：特训目标页 → 按钮「更换特训目标」
- **消失**：点右上关闭、点「清除目标」、选中代理人后确认

| 元素 | 动作 | 去向 |
|---|---|---|
| 按钮-关闭 | 点 | 回特训目标页（保留原目标） |
| 代理人格子 | 点 | 选中（黄框），需再确认才生效 |
| 按钮-特训方案 | 点 | 打开该代理人的养成方案（未建档） |
| 按钮-清除目标 | 点 | 清空特训目标，回特训目标页（页面变空态） |

## 识别特征

- **标题「更换特训目标」**：左上（`pc_rect` 390,228 - 620,288），`id_mark`。
- 弹窗整体覆盖在特训目标页之上，背景是变暗的游戏画面。

## 布局

- 代理人网格：横 6 列、竖 2 行可见，可上下滚动（右侧有滚动条），位置 `385,390 - 1560,830`。
- 每格内容：头像 + 右上稀有度角标（S）+ 名字（白色）+ `Lv.60`。
- 当前选中的格子有**黄色描边**，左上角一个蓝色圆点。
- 名字文本在格子下半部，**白色**，与灰色 `Lv.XX` 明显区分。

## 定位代理人的做法

1. 对 `区域-代理人网格` 整块 OCR，丢弃 `Lv.` 开头的文本，剩下的就是代理人名字。
2. 用 `difflib` 把 OCR 文本跟目标名字模糊匹配（游戏角色名可能不在项目 `AgentEnum` 里，例如「雷米埃尔」「薇蒂安」，所以**不查枚举**）。
3. 命中后点击该名字框中心**往上偏移**（头像在名字上方，`click_offset` 约 -80px）。
4. 没命中就向下滚动一屏再试，最多 3 屏。

## 备注

- 弹窗里的名字与 `Lv.60` 是**同一个格子的两行**，按 y 聚类时要注意别把 `Lv.60` 当成独立条目。
- 「特训方案」按钮打开的是另一个画面（养成指南），未建档。
