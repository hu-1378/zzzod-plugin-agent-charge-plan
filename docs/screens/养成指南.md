# 养成指南

从「养成方案-详情」页点「更多方案」进来的方案总览页。**「养成材料计算」的入口在本页代理人名字正下方**——这是拿到带材料名的缺口明细的唯一路径。

## 何时出现 + 状态流转

- **入口**：养成方案-详情页 → 按钮「更多方案」
- **去向**：

| 元素 | 动作 | 去向 |
|---|---|---|
| 按钮-返回 | 点 | 回养成方案-详情 |
| 按钮-养成材料计算 | 点 | 弹 [养成材料计算](养成材料计算.md) 弹窗 |
| 按钮-应用方案 / 切换方案 | 点 | 未建档 |
| 左侧导航 | 点 | 属性&等级 / 驱动盘 / 音擎 / 技能 / 推荐队伍 / 补充建议（各页未建档） |
| 顶部代理人横条 | 左右箭头 / 点头像 | 切换代理人；当前选中有黄色描边 |

## 识别特征

- **标题「养成指南」**：左上（`pc_rect` 160,20 - 400,85），`id_mark`。
- 左侧竖排 7 个导航项，第一项「方案概览」选中时是**黄底**。

## 关键区域

| 区域 | 位置 | 说明 |
|---|---|---|
| 区域-角色名 | 755,133 - 945,190 | 粉色横幅上的白色粗体，前面带 S 徽标 |
| 按钮-养成材料计算 | 820,175 - 1110,235 | 名字正下方，深色圆角条 + 右侧三角 |
| 区域-代理人横条 | 765,8 - 1655,92 | 一排头像，当前项黄框 |
| 区域-左侧导航 | 160,165 - 405,620 | 7 个导航项 |

## 备注

- 本页出现的时机很特定：必须先有「特训目标」才能从「查看攻略」走到养成方案详情，再点「更多方案」进来。**没有设特训目标时这条路走不通。**
- 顶部横条和左侧导航的其它页都还没截图，只建了本页需要的区域。
