# 养成材料计算

游戏自带的养成材料计算器。全代理人常驻开放（不需要拥有该角色），支持「智能计算」（按游戏培养建议）和「自定义计算」（自由设代理人/技能/音擎目标等级）。输出「需要获取的材料」和「养成材料明细」两页。

## 何时出现 + 状态流转

- **入口**：养成指南页 → 角色名下方的「养成材料计算 ▶」→ 弹窗
- **三步**：设置（滑块）→ 点「确定」→ 结果页（两页：图标横排 / 明细表）
- **去向**：

| 元素 | 动作 | 去向 |
|---|---|---|
| 按钮-重置 | 点 | 回到该角色的默认目标等级 |
| 按钮-确定 | 点 | 出结果（同一弹窗内切换为结果页） |
| 按钮-关闭 | 点 | 关弹窗回养成指南 |

## 识别特征

- **标题「养成材料计算」**：`pc_rect` 430,100 - 700,165，`id_mark`。
- 设置页与结果页共用同一弹窗外框，靠内容区分。

## 设置页（首版不用）

从上到下：提示条 → 「代理人等级」→ 「技能等级」5 行（普通攻击 / 闪避 / 支援技 / 特殊技 / 连携技 / 核心技）→「音擎（选填）」→ 底部「重置」「确定」。

- 每行是「当前等级 —— 滑块 —— 目标等级」。目标 = 当前时显示「目标等级与起始等级相同，无需计算」。
- 音擎是**选填**，所有角色都一样，不管有没有装。点「添加 +」进音擎选择弹窗（按类型筛选，如「异常 ▼」）。

> 首版固定用游戏默认的「智能计算」直接点「确定」，只读结果页。要支持自定义计算时再补这部分的区域。

## 结果页一：需要获取的材料

图标横排（`pc_rect` 460,245 - 1270,470），一行 5 个：

- 带数字的（如 `75`、`140`）= 仍需获取这么多
- 显示「已满足」的 = 已达标

这是最快的「有没有缺口」判断，但**拿不到材料名字**（只有图标）。

## 结果页二：养成材料明细

按分区列出（如「代理人技能升级」「音擎强化&进阶」），每个分区右上角是该类消耗的丁尼总数。

表格四列（`pc_rect` 490,245 - 1480,1010）：

| 列 | 区域名 | x 范围 | 内容 |
|---|---|---|---|
| 养成材料 | 列-材料名 | 500-950 | 图标 + 材料名（白色） |
| 所需 | 列-所需 | 990-1120 | 数字 |
| 已有 | 列-已有 | 1150-1290 | 数字 |
| 仍需获取 | 列-仍需获取 | 1300-1470 | 黄字数字 = 缺口；绿色对勾 = 已满足 |

要点：

- **列 x 固定、行 y 随滚动变化** → 先整块 OCR，再按 x 把文本分到四列，按 y 聚成行。
- 行尾是「绿色对勾」时该行没有数字，要当成「已满足」而不是解析失败。
- 长数字（丁尼 `8772526`）没有千分位，直接是连写数字。
- 界面自己写着 **「仓库数据计算存在10分钟左右延迟」** → 刷完立刻重读会读到旧值，不能用来做「跑一次验一次」的精确判定。

## 备注

- 「需要获取的材料」里的图标没有名字，要建图标模板才能对应到材料；明细表有名字，**优先读明细表**。
- 明细只覆盖该角色当前方案涉及的材料，**不是全仓库库存**。要全量库存得进仓库材料页。
