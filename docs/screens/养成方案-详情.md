# 养成方案-详情

从特训目标页点「查看攻略」，或从代理人界面进「代理人攻略」后看到的养成方案页。左侧是培养配置，右侧是「材料预览」——**这一栏直接给出每种材料的「已有 / 所需」**。

## 何时出现 + 状态流转

- **入口**：特训目标页 → 按钮「查看攻略」
- **去向**：

| 元素 | 动作 | 去向 |
|---|---|---|
| 按钮-更多方案 | 点 | 养成指南（方案列表，**未建档**） |
| 按钮-快速设置 | 点 | 未建档 |
| 按钮-设置为目标 | 点 | 未建档（等价于设特训目标） |
| 顶部代理人横条 | 点/滑动 | 切换代理人 |

## 识别特征

- **「更多方案」按钮**：左上角（`pc_rect` 190,22 - 412,82），`id_mark`。只有本页面有这个按钮。
- 蓝色横幅上显示代理人名字（`pc_rect` 120,133 - 360,187）。

## 页面结构

左侧主区三个分区（各自带「卓越计划 / 绳匠之选」标签 + 刷新按钮）：

| 分区 | 内容 |
|---|---|
| 代理人 | 等级（如 `等级60`）+ 升阶状态图标 |
| 技能 | 6 个技能等级（`等级11` ×5 + `等级7`），已满的图标带绿色对勾 |
| 驱动盘 | 套装名 + 件数（`4` / `2`）+ 等级 + 词条达标勾 |

右侧「材料预览」面板（`pc_rect` 1145,108 - 1815,1010）按同一套分区列出材料行，每行是：

```
材料图标 + 进度条 [已有/所需] + 按钮（获取 / 养成 / 装备）
```

进度条上的文本就是缺口判断依据：`60/159`（差 99）、`83/33`（已够）、`8772526/320000`（丁尼）、`3422/120`（已够）。够了的显示白底黄字，不够的是绿条。

## 备注

- 这一栏是**同页面最省事的缺口来源**：一次 OCR 就能拿到该角色所有材料的「已有/所需」，不需要进「养成材料计算」弹窗。
- **进入养成指南的路径**（已确认）：本页点「更多方案」→ 养成指南。养成指南里角色名下方才有「养成材料计算」按钮，点开出弹窗（见 [养成材料计算](养成材料计算.md)）。
- 但养成指南页**尚未截图建档**。好在右侧「材料预览」已经给了同样的「已有/所需」，**首版优先用这一栏，不必进养成指南**；等需要「自定义计算」（自由设目标等级、指定音擎）时再补那一页。
